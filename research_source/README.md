# Research harness source archive

These are research workspace Python sources, separate from the portable synthetic demo. Source/export hashes are recorded in SOURCE_PROVENANCE.json. Local path prefixes have placeholders; no request/response artifacts, credentials, native questions, gold, reference passages or third-party definition files are copied.

The archive includes the extraction/query workflow, bounded grading/reporting scripts, admission/telemetry helpers, graph interface and supporting package modules. It records how the research was implemented; it is not a turnkey rerun of the paid campaign. Imports/default paths refer to the original experiment layout.
